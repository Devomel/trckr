# trckr

MVP Android-трекер бігу: час + BLE пульсометр (GPS свідомо не використовується через постійний спуфінг) (Magene H64/H303 та будь-який нагрудний датчик зі стандартним Heart Rate Service).

## Встановлення
APK збирає GitHub Actions на кожен push: **Releases → `latest` → `trckr.apk`**. Debug-ключ закомічено (`app/debug.keystore`), тож нові збірки ставляться поверх старих без втрати даних.

## Як користуватись
1. Дай дозволи (Bluetooth, сповіщення).
2. Одягни датчик, натисни «Пульсометр: вибрати…» і вибери пристрій (позначений ♥).
3. Натисни **СТАРТ**. Запис іде у foreground-сервісі — екран можна вимкнути.
4. **СТОП** → сесія зберігається в історії. Тап по сесії → «Експорт» (CSV у `Download/trckr`; для старих сесій з GPS — ще й GPX).

## Дані
`files/sessions/<yyyyMMdd_HHmmss>/`:
- `track.csv` — `t_ms,lat,lon,alt,acc,speed,hr,dist_m`, 1 рядок/сек (GPS-колонки порожні), пишеться наживо (переживає краш);
- `summary.json` — підсумки;
- `track.gpx` — GPX 1.1 з `gpxtpx:hr` (лише для старих сесій з GPS).
